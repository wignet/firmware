**First install for the Waveshare ESP32 Driver Board with a 3.52-inch black-and-white panel**

- Downloadable USB firmware for the Waveshare ESP32 Driver Board with a 3.52-inch black-and-white e-paper panel (NQ01, 240x360 native, shown in landscape as 360x240).
- This image is for first installation over USB. Updates over the air are not offered for this board yet.
- Verified on a bench unit with the panel's Display Config switch set to B. The firmware logs `Busy Timeout!` during refresh; the image still completes, as documented in `esp32/README.md`.
