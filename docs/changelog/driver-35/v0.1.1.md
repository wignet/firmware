**Over-the-air updates for the Waveshare ESP32 Driver Board with a 3.52-inch black-and-white panel**

- This version carries a larger partition table with two app slots. Install it once over USB; afterwards the board installs new versions over the air, after the server offers them.
- The update is signed and confirmed by the server. If the new image does not confirm, the board rolls back to the previous one.
- Bench-tested with the full OTA contract: valid offer, refused and failed offers, forged and replayed confirmations, and rollback on a missing confirmation.
- The panel still logs `Busy Timeout!` during refresh; the image still completes.
