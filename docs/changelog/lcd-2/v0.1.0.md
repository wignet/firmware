**First install and over-the-air updates for the Waveshare ESP32-S3-LCD-2**

- Downloadable USB firmware is now available for the Waveshare ESP32-S3-LCD-2 (2" colour LCD).
- This image is for first installation and resets saved Wi-Fi settings. After this one USB install, it installs updates over the air.
- The OTA flow (signed offers, confirmation, rollback) passed the bench on a 2" LCD board on 2026-11-03.
