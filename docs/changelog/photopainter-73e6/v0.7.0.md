**Waveshare PhotoPainter 7.3": alarms that play a scene**

- A planned event, an alarm for example, can carry a scene: the PhotoPainter keeps it in flash ahead of time and plays it at the event's time instead of ringing. The scene runs its own music, snoozes on a press and ends when the event's window closes.
- If the scene cannot play, because it did not fit in flash or did not download in time, the event's sound rings as before.
- Updates install on battery from 25 % charge, not only when plugged in.
- Install it over the air from the Wignet owner page; if an update does not start, the board goes back to the previous version by itself.
