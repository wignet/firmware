**Waveshare AMOLED 1.8: first install over USB, PhotoPainter 7.3" over the air**

- Waveshare ESP32-S3-Touch-AMOLED-1.8: a first install over USB. This image resets the saved Wi-Fi settings. This board does not install updates over the air yet.
- Waveshare PhotoPainter 7.3" (Spectra 6): installs official releases itself, from its page or through its assistant. It goes back to its previous version on its own if the new one doesn't start.
- The PhotoPainter image is built from the same source tree as the AMOLED 1.8 image: this release changes code the two boards share.
