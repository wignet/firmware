**Over-the-air updates for the 7.5" black-and-white**

- The frame installs official releases itself, from its page or through its assistant.
- It goes back to its previous version on its own if the new one doesn't start.
- It can't tell whether it is plugged in: say so on its page, or updates aren't offered.
- Once, over USB: this version gives it a new partition table (see the flashing guide).
