**Raspberry Pi Zero W HDMI TV**

- The startup and Wi-Fi setup screens have a new look: cream text on black, in English.
- Everything to read now stays inside the TV's overscan margins, so a TV that crops the edges of the picture no longer cuts it off.
- The TV now tells the server how much room its update slot has, so it is never offered an image too large to install.
- Install it over the air from the Wignet owner page. If an update does not start, the TV goes back to the previous version by itself.
