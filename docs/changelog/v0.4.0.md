**Over-the-air updates for the HDMI TV**

- The Wignet TV (Raspberry Pi Zero W) installs official releases itself, from its page or through its assistant.
- If the new version doesn't start properly, it goes back to the previous one within ten minutes.
- Once: flash this release's SD card image (`wignet-raspberry_pi_hdmi-sdcard.img.xz`); earlier cards can't update.
- E-paper frames: nothing changes in this version.
