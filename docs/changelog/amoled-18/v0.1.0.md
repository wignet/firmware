**First install for the Waveshare AMOLED 1.8**

- Downloadable USB firmware is now available for the Waveshare ESP32-S3-Touch-AMOLED-1.8.
- This image is for first installation and resets saved Wi-Fi settings. After this one USB install, it installs updates over the air.
- The release candidate was tested by the device owner on an AMOLED 1.8 board.
