**Waveshare AMOLED 1.8 over-the-air updates**

- Later firmware for the Waveshare ESP32-S3-Touch-AMOLED-1.8 installs over the air, from the Wignet owner page, once the board reports `ota1`.
- Install a version that declares `ota1` over USB once first. Updates after that do not need a cable.
- If an update does not start, the board goes back to the previous version by itself.
