**Waveshare 7.5" driver board: scenes for planned events**

- A planned event can carry a scene: the board keeps it in flash ahead of time, starts it at the event's time and ends it when the event's window closes, then gives the screen back to its slideshow.
- A scene can react to the event starting and ending, for example to turn to another page when the event begins.
- Install it over the air from the Wignet owner page. If an update does not start, the board goes back to the previous version by itself.
