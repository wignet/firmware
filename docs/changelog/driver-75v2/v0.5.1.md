**Waveshare 7.5" driver board: first target release**

- Nothing changes on the screen: this version is v0.5.0 rebuilt from current firmware, released under the board's own tag so later 7.5" updates follow it.
- Install it over the air from the Wignet owner page once the board reports `ota1`. A board still on the old layout takes one USB install first (the factory image resets Wi-Fi).
- If an update does not start, the board goes back to the previous version by itself.
