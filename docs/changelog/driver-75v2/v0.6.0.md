**Waveshare 7.5" driver board: scenes with buttons**

- The board plays paced scenes: pages an agent sends that change when you press the BOOT button or after a set time. The screen redraws each page in full, about 5 seconds, and waits a moment after each redraw before the next.
- A scene that ends itself, or that you end by holding BOOT for 5 seconds, gives the screen back to its slideshow.
- The board measures its own redraw time and the room it has for pages, and tells the server, which refuses a scene that would not fit.
- Install it over the air from the Wignet owner page. If an update does not start, the board goes back to the previous version by itself.
